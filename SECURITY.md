# Safety and security

This project is for research and simulation. It is not a safety-certified planner or controller. Never connect its decisions directly to motors, industrial robots, medical robots or other physical systems.

Use independent collision detection, safety-rated monitored stops, workspace limits and certified controllers. Report vulnerabilities through GitHub's private vulnerability reporting rather than a public issue.

Do not commit credentials, production robot logs, private maps, customer data, proprietary code, model weights or deployment configuration.
